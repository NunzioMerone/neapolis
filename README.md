# Chiesa Evangelica Neapolis

Sito vetrina statico per la Chiesa Evangelica Neapolis di Napoli.

## Struttura

- `index.html`: pagina principale.
- `assets/css/styles.css`: stile centralizzato.
- `assets/js/content.js`: testi, link e contenuti centralizzati.
- `assets/js/components.js`: componenti HTML generati via JavaScript.
- `assets/js/main.js`: interazioni, animazioni e ottimizzazioni.

## Pubblicazione

Il sito è pensato per GitHub Pages e funziona senza build step.
